# RULES — irv-flow. Inherited from mimicry's docs/loop/rules.md where stated; frozen 2026-10-02.

- RULE 1 — STOPPING. IF-01 ends on its own §7 conditions. There is no calendar limb (mimicry 2026-08-25 ruling stands).
- RULE 2 — CASH. Struck in wallet-independence 2026-08-14 as a personal-liquidity rule; not carried.
- RULE 5 — A RESULT COUNTS only if (a) a stranger can execute the rule from the artifact alone, (b) ≥ 30
  independent observations, (c) it beats a declared null by a margin declared before the test, (d) byte-identical
  replay from pinned records, (e) it names what it lets the operator do with money. Amendment 2/3 (2026-08-21/25):
  the goal is a cash machine that compounds small wins; tail-carried means are disqualified (drop-top-5 % gate).
- RULE 7 — one contract in flight per repo. Family-wise error across concurrent paper contracts is accepted openly.
- RULE 8 — finder/referee: the operator writes his own determination before reading the agent's; divergences are
  logged in docs/loop/divergence.md.
- LOSS-FIRST (2026-08-27): rank and gate on loss metrics first; a strategy holding losers longer than winners fails
  regardless of headline P&L.
- NO BOILERPLATE (2026-09-09): every line production-grade.
